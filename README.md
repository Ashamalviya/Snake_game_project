# 🐍 Snake Game

A simple and interactive Snake Game built using HTML, CSS, and JavaScript.

## 🎮 Features

* Simple and easy controls
* Score tracking
* Interactive gameplay
* Beginner-friendly project

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ▶️ How to Play

Use the arrow keys to control the snake and collect the food. Avoid hitting the walls or yourself.

## 📌 Project

This project was created to practice JavaScript, game logic, and basic web development.
